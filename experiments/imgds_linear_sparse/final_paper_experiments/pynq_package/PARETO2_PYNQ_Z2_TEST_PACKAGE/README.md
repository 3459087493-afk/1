## Prerequisites for Board Testing

1. Generate Vivado bitstream from PARETO2 HLS IP:
   ```bash
   cd <vivado_project_dir>
   vivado -mode batch -source generate_bitstream.tcl
   ```
2. Copy `pareto2.bit` and `pareto2.hwh` to this directory
3. Copy this entire package to PYNQ-Z2:
   ```bash
   scp -r PARETO2_PYNQ_Z2_TEST_PACKAGE/ xilinx@192.168.2.99:/home/xilinx/
   ```
4. SSH into PYNQ-Z2 and run:
   ```bash
   ssh xilinx@192.168.2.99
   cd /home/xilinx/PARETO2_PYNQ_Z2_TEST_PACKAGE
   sudo python3 run_pareto2_pynq_test.py
   ```
